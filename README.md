## 能做什么

| 功能 | 使用方式 |
| --- | --- |
| 环境安装 | 一键准备官方 ComfyUI Portable 和 Python，可选择同时安装 H3 模型 |
| 已有环境连接 | 复用已有模型，支持本地服务、Portable 和适配过的 venv 环境 |
| 视频生成 | 首帧图生视频；无需图片的文生视频为试用功能 |

| 原生节点编辑 | 在 ComfyUI 编辑器搭建工作流，桌面版可保存编辑结果回库 |

| 资源与诊断 | 根据设备展示模型建议、依赖问题、官方文件页和安装教程 |

## 快速开始

### 1. 安装启动器

当前交付为本地安装包，尚未发布线上下载链接。在 `dist/v0.1.5/` 中打开：

```text
luckyx-Studio-Setup-0.1.5-x64.exe
```

按向导选择安装目录。升级时先退出旧版，再覆盖安装，无需先卸载。安装包目前未签名。

免安装版位于同目录的 `win-unpacked/`，打开 `luckyx. Studio.exe`，保留同目录其他文件。

### 2. 没有 ComfyUI 或模型

进入左下角 **安装与连接**，选择安装内容和磁盘，点击 **检查配置与下载量**。

| 方案 | 适合谁 | 当前下载量 | 首次建议可用空间 |
| --- | --- | --- | --- |
| 只安装 ComfyUI | 先准备环境，之后自行选择模型 | 约 1.9 GiB | 约 14.3 GiB |
| ComfyUI + H3 模型 | NVIDIA RTX、约 16 GB 显存及至少 24 GB 内存的条件试用设备 | 约 41.0 GiB | 约 53.5 GiB |

以上是当前固定环境包的参考值，实际以检查页面为准。一键安装当前仅适配已识别的 NVIDIA RTX 20 系列及更新设备；AMD、Intel、旧显卡或检测失败时请使用页面中的官方教程。

确认清单后勾选下载提示，点击 **一键安装并配置**。程序会下载、校验、解压、配置路径并尝试启动与检查引擎。过程中可暂停，重新检查后继续下载。安装目标为所选目录下的 `luckyx-environment`，已有目录不会被覆盖。

![安装方案选择与已有环境连接](assets/readme/setup.webp)

只安装基础环境不会下载 H3 权重，也不会直接获得 H3 生成能力。自动安装失败时展开 **手动教程**，处理对应错误后继续，或连接手动安装的环境。

### 3. 已有 ComfyUI

在同页下方 **连接已有环境** 填写：

- **运行环境**：包含 `ComfyUI` 和独立 Python 的根目录。
- **模型目录**：已有的 `ComfyUI/models`，无需重新下载。
- **作品输出／输入素材**：你希望保存视频与素材的位置。
- **服务地址**：本机 HTTP 地址，通常为 `http://127.0.0.1:8188`。

点击 **保存并检查**。Portable 可由启动器启动；普通手动安装可先自行启动，再连接本机服务。更改模型目录后，还需保证 ComfyUI 的模型搜索路径配置一致。

## 使用教程

### 生成第一段视频

1. 在首页启动或连接引擎，检查模板依赖。
2. 打开 **创作工作台 → 生成视频**。
3. 选择图生视频并上传首帧；文生视频模式无需图片。
4. 填写动作、镜头和声音提示词，设置分辨率与时长。
5. 初次建议使用图生视频默认值：`864×480`、约 `5.17 秒`。
6. 点击 **生成视频**，在 **任务与作品** 查看状态，完成后导出 MP4。

![生成方式、提示词、分辨率与时长](assets/readme/generate.webp)

截图展示文生视频参数入口；右侧为历史图生视频记录，不是这次提示词的生成结果。时长会换算为模型允许的帧数，例如输入 10 秒，实际约为 10.13 秒。更大的尺寸与更长的视频通常需要更多显存和时间。

### 删除历史任务

在 **任务与作品** 中选择记录，点击右侧 **删除历史记录**，核对提示后点击 **确认删除记录**。点击 **保留记录** 可取消。删除后该条任务及对应作品记录不再显示，但磁盘上的视频、素材和工作流文件会保留。

![删除历史记录前的确认提示](assets/readme/delete-history.webp)

### 新建或导入工作流

1. 打开 **工作流库 → 我的工作流**。
2. 点击 **新建工作流** 开始空白画布，或 **导入 JSON** 选择已有节点／API 工作流。
3. 引擎就绪后，在桌面版点击 **打开节点编辑器**，连接和调整节点。
4. 回到启动器点击 **保存编辑结果**，也可以 **导出 JSON** 留存。

![工作流新建、导入与管理](assets/readme/workflows.webp)

导入工作流不会自动生成、安装节点或下载模型。浏览器预览需导出 JSON 后拖入原生 ComfyUI，编辑后再更新 JSON。工作流库中的自定义流程在原生编辑器运行，不套用精选模板的参数表单。

### 改造已有视频

在 **创作工作台 → 改造视频** 选择方式：

| 方式 | 需要准备 |
| --- | --- |
| 风格转换 | 原视频、目标风格提示词 |
| 局部换人物 | 原视频、对齐的逐帧黑白人物遮罩、人物提示词 |
| 换背景 | 原视频、对齐的逐帧黑白背景遮罩、背景提示词 |

检查依赖，添加到工作流库，在原生编辑器上传素材和手动运行。局部改造的遮罩中，白色区域重绘、黑色区域受保护；遮罩需与原片尺寸、帧率和时间对齐。

![三种视频改造工作流](assets/readme/transform.webp)

这些流程还需额外的 FunUnion 控制权重，完整 H3 一键安装方案不包含它。目前不会自动生成遮罩，也不提供精确人物身份锁定；改造效果与显存需求仍需试跑确认。

### 调整界面反馈

进入 **设置与诊断 → 常规 → 界面偏好**，调整以下选项，修改立即生效并保存在当前设备：

| 选项 | 效果 |
| --- | --- |
| 动态效果 → 减少动态 | 去掉缩放、位移和旋转，仅保留短淡入淡出 |
| 透明效果 → 使用实色 | 弹窗遮罩和提示背景改用实色 |
| 对比度 → 提高对比度 | 加强文字与边框的辨识度 |

默认 **跟随系统**；系统已启用减少动态时，应用也会遵循。键盘打开和关闭弹窗即时响应，按 Tab 切换控件，按 Escape 关闭弹窗或较窄窗口的任务面板。

![界面偏好与路径设置](assets/readme/preferences.webp)

### 寻找模型和安装教程

进入 **资源中心 → 模型推荐与教程**，查看设备建议，选择对应模型，打开官方文件页和截图教程。模型建议代表试用方向，不保证在每台电脑上成功运行。

![模型推荐和官方安装教程](assets/readme/models.webp)

## 更新、卸载与数据

- **升级**：复用固定数据目录，保留设置、任务、预设和工作流副本。
- **卸载**：默认保留数据，重新安装后可继续使用。
- **主动清理**：勾选后删除应用设置、历史、工作流副本及缓存；视频、原图、外部模型和 ComfyUI 环境保留。
- **数据位置**：桌面安装版默认使用 `%APPDATA%\luckyx-studio\studio`；开发和浏览器预览使用各自的 `.runtime` 目录。

安装包与本地更新日志位于 `dist/`，不提交 Git。图片教程位于 `assets/readme/`，随 README 保存，避免在线查看时图片失效。

## 常见问题

<details>
<summary>为什么按钮不可点击？</summary>

先检查引擎状态和模板依赖。图生视频还需要首帧图片和提示词；安装还需要有效计划、足够空间与确认勾选。浏览器预览禁止真实安装，原生编辑器需要桌面版和已启动的 ComfyUI。

</details>

<details>
<summary>下载失败或空间不足怎么办？</summary>

下载会校验大小与 SHA256。暂停或网络失败保留进度，重新检查后继续；空间不足可更换磁盘。目录已存在时请连接已有环境或选择新位置。不要删除正在使用的模型目录来“重装”。页面内有 ComfyUI 与 H3 官方教程。

</details>

<details>
<summary>打开节点编辑器出现 undefined.path？</summary>

v0.1.3 已修复加载 API 工作流时漏传文件名的问题。退出旧版后覆盖安装新版。若仍无法打开，确认原生 ComfyUI 页面可访问，并查看设置与诊断中的启动日志。

</details>

<details>
<summary>能完全离线使用吗？</summary>

已有环境和完整模型可在本地运行。一键安装、读取官方清单和打开教程需要网络。启动器不会把生成素材上传到云端；原生 ComfyUI 中自行安装的第三方节点行为由对应节点决定。

</details>

## 从源码运行

需要 Node.js **22.12 或更高版本**。Windows 打包使用 Electron 与 NSIS。

```bash
npm ci
npm run dev
```

检查、测试与打包：

```bash
npm run check
npm test
npm run build
npm run dist
```

浏览器预览：

```bash
npm run preview
```

打开 `http://127.0.0.1:4173/`。当前自动安装环境固定为官方 ComfyUI `v0.39.0`，解压器随安装包提供。应用窗口默认 `1440×1024`，常规最小 `1200×720`，不超过屏幕工作区。

开发预览提供 **Demo data / Worst case / Empty / One / 1,000 rows** 数据切换工具。示例模式只读，阻止安装、写入和生成；可点击 **隐藏测试工具** 收起。正式安装版不包含这些工具。
